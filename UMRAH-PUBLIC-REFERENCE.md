# Public Umrah planning page

Reference: https://www.trips.pk/umrah/, inspected 2026-10-19.
The user confirmed permission to reuse reference descriptions and images.

Implemented the landing-page planning categories: eight Pakistan departure
cities, six travel durations, hotel/economy/VIP/family/seasonal preferences,
17 international inquiry origins and Saudi/Qatar/Dubai extension requests.
Service explanations, hotel advice, a four-step booking guide and FAQs use
wording suited to this business, without assuming supplier relationships.
No Trips.pk reviews, company credentials, contact numbers or payment details
are presented as Zayan Ahmed Travels facts. No external assets are hotlinked.

The planner sends its current selections in the existing Umrah inquiry message.
It does not search or reserve inventory. The existing server validates the
combined message length. Public packages still come solely from the existing
published/active API; private supplier drafts remain private. Removed fictional
demo packages and placeholder art from the public list.

Import limitation: the live reference Islamabad page has an empty package-table
container, while the search reader shows cached rates. Duration and occupancy
context cannot be verified from those rows. No Trips.pk supplier package prices,
hotel records or images have been imported. This is a landing-page adaptation,
not a claim that every linked source page or supplier offer was copied. A current
structured supplier export is needed to import the complete offer catalogue
without guessing hotel nights, occupancy, dates or rate conditions.

No schema, migration, production data, credentials or upload setting changes.
