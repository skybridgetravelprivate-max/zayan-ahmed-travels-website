Plus Jakarta Sans, Latin variable normal font, from
`@fontsource-variable/plus-jakarta-sans` version **5.3.0** on the npm registry.
The original SIL Open Font License is included in `OFL.txt`.

Bundled locally so production builds do not depend on Google Fonts requests.
The existing CSS variable and 400–700 weight range are preserved.

The staff workspace also bundles Inter Variable 4.1 and JetBrains Mono Regular 2.304 from the tagged upstream releases. Their original SIL Open Font Licenses are included in `Inter-OFL.txt` and `JetBrainsMono-OFL.txt`.

- [Inter variable WOFF2](https://github.com/rsms/inter/blob/v4.1/docs/font-files/InterVariable.woff2)
- [JetBrains Mono regular WOFF2](https://github.com/JetBrains/JetBrainsMono/blob/v2.304/fonts/webfonts/JetBrainsMono-Regular.woff2)
